Connect Interactive Brokers

  1. In Client Portal, open Performance & Reports → Flex Queries and create an Activity Flex Query. Add the sections Account Information, Net Asset Value (NAV) in Base, Open Positions (Summary) and Cash Report; Conversion Rates is optional. Format XML, period Last Business Day, date format yyyyMMdd. Save it and note the Query ID.
  2. Under Flex Web Service, generate a token (lifespan up to a year), ideally limited to the server's IP address.
  3. Put both in .env as IBKR_FLEX_TOKEN and IBKR_FLEX_QUERY_ID, then run docker compose up -d.

The first sync loads a year of history; after that the server syncs every morning.
